# SquadHub

Starter Windows desktop app with automated installer build.

## Build and download
Open Actions → Build SquadHub Windows Installer → Run workflow. When successful, download the SquadHub-Setup-Windows artifact and extract SquadHub_Setup.exe.

## Local build
Install .NET 8 SDK and Inno Setup 6, then run BuildSetup.ps1 in PowerShell.

## Status
Starter desktop shell only. Online accounts, friends, cloud leaderboard, Discord OAuth/RPC, and game detection are not yet implemented.
